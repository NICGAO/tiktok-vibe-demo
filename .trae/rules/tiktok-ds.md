1. Only use `@byted-tiktok/tux-web` for components. `Button` component has "Capsule" prop and different sizes. Use `Text` for text. Use `Avatar` for avatar. Don't overuse `Separator` unless you did see it from the design reference. Use `Sheet` for bottom sheet.
2. Only use `@byted-tiktok/color` for colors. 
3. Only use `@byted-tiktok/tux-icons` for icons. Search for `chevron` variants over `arrow` for navigation icons. Draw placeholder (div square with `UIShapeSuccess` as background) for icons you cannot find. 
4. Keep the repo’s file structure and routing; add pages/components within existing navigation.
5. Use placeholders (div with `UIShapeNeutral4` as background ) to represent images. 
6. Check `tiktok-ds.md` and `tiktok-design-system` skills if you have any doubt.
